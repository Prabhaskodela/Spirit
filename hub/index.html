SpiritHUB

Connect your Supabase project

  1. Create a free project at supabase.com.
  2. Open SQL Editor, paste hub/schema.sql and run it.
  3. In Authentication → Sign In / Providers, turn off Confirm email.
  4. Copy the project URL and anon (public) key from Project Settings → API into hub/config.js, then reload.
